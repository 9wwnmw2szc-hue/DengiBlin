# Подключение T-Invest Sandbox

v0.2 умеет читать данные и сохранять историю. BUY/SELL отсутствуют; адрес реального контура не используется. Токен не вводится в браузере, не передаётся в чат, не сохраняется в Git, Redis или бизнес-БД.

## Первое подключение

1. Запустите MarketBrain через Docker Compose и зарегистрируйте аккаунт.
2. Получите **Sandbox token** в настройках API T-Invest. Нужен доступ к виртуальному счёту. Создайте Sandbox-счёт средствами брокера, если его ещё нет: v0.2 сама не создаёт и не пополняет счета.
3. В локальном терминале проекта выполните, заменив email на email зарегистрированного пользователя:

```sh
docker compose exec backend python -m app.provision_token --email user@example.com
```

Команда запросит токен через скрытый ввод в терминале. Не вставляйте токен в аргументы команды, переменные shell, сообщения или файлы проекта. При успешной проверке будут сохранены только зашифрованный файл и отдельный ключ.

4. Откройте **Настройки → T-Invest Sandbox**, выберите виртуальный счёт и нажмите **Обновить данные**.
5. На экране **Рынок** появятся полученные котировки и история свечей. Щелчок по карточке акции открывает OHLCV.

Если команда сообщает ошибку, ранее действующее подключение не заменяется. Ошибки не выводят токен и текст ответов брокера.

## Замена и проверка

Повторите команду скрытого ввода для того же email. Новый токен проверяется перед заменой. Старый зашифрованный файл удаляется; выбранный счёт сбрасывается, чтобы пользователь заново подтвердил подключение. Незавершённая загрузка со старым токеном не сможет сохранить данные после смены версии подключения.

Кнопка **Проверить подключение** проверяет сохранённый серверный токен и обновляет список доступных Sandbox-счетов. **Обновить данные** ставит загрузку в очередь, повторные запросы объединяются в течение 60 секунд.

## Отключение и отзыв

Кнопка **Отключить** требует подтверждения, отключает локальное подключение, блокирует последующие загрузки и удаляет серверную копию токена. История данных и решений сохраняется.

Это **локальное отключение**, а не отзыв credential у T-Bank. Для окончательного отзыва удалите токен в настройках API у брокера. Если хранилище недоступно при удалении, интерфейс покажет предупреждение, а аудит получит SECRET_DELETE_FAILED. Подключение всё равно останется отключённым.

## Шифрование и ротация

Ключи лежат в Docker volume `broker_keys`, зашифрованные токены — в `broker_tokens`; данные торговли — в PostgreSQL. Файлы секретов доступны только контейнерному пользователю приложения, каталоги имеют режим 0700, файлы — 0600. Используется Fernet authenticated encryption, пользователь привязан к encrypted payload. Все чтения и ротации защищены файловой блокировкой.

```sh
docker compose exec backend python -m app.provision_token --rotate-key
```

При ротации старые ключи сохраняются до перешифрования всех файлов. После успешной ротации остаётся новый ключ. Прерывание операции не делает неперешифрованные токены нечитаемыми. Не удаляйте `broker_keys` без backup: ciphertext без ключа восстановить нельзя. Не храните backup ключей рядом с backup токенов. Внешняя KMS и независимые production-роли остаются отдельной задачей.

## Семантика данных

- Доступные рублёвые акции класса TQBR сохраняются как справочник. Наличие в справочнике не разрешает торговлю и не подтверждает ликвидность.
- Список наблюдения ограничен 5 инструментами на пользователя. Отсутствующие тикеры отображаются явно.
- История: последний день часовых свечей при каждой загрузке, накопление истории в PostgreSQL. Повторная загрузка не дублирует свечи и котировки.
- Время котировки — время сделки у брокера. Свежая загрузка вчерашней цены не делает её свежей. По умолчанию цена старше 30 секунд помечается устаревшей.
- Завершённость свечи сохраняется отдельно. Неполная свеча не должна формировать торговый сигнал.
- Все необходимые ответы сначала собираются и проверяются; затем один атомарный commit сохраняет нормализованные данные и полный снимок. Ошибка части запроса не публикует частичный снимок.
- Брокерский Sandbox-портфель и локальные 1 000 ₽ MarketBrain — разные сущности. Сверка и единый торговый Portfolio Manager будут реализованы отдельно.
- Ошибки API, отозванный токен, отсутствие счёта или нарушение целостности переводят подключение в ERROR; новые покупки остаются заблокированными.

Автообновление примерно раз в 5 минут и ручная очередь служат сбору истории. **Это ещё не streaming, не reconciliation и не автономный торговый цикл.**

## Проверка без реального токена

Тесты используют явно обозначенные fixtures и httpx MockTransport. Эти данные никогда не попадают в интерфейс продукта. Без предоставленного владельцем Sandbox-токена проверка реального сетевого подключения и прав у брокера не заявляется выполненной.
